# Preface

This documentation provides guidance for developing applications for HSR using ROS 2.  
It is intended for use with the simulation environment and is publicly available to everyone.

For information on setting up, connecting to, and operating a physical HSR robot,  
please refer to [HSR I/O](https://www.hsr.io/).  
The documentation for physical robots is available only to HSR community members.
